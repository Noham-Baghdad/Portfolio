SAE 103 : Artisan Website

This website was my first real project using HTML, CSS, and PHP. The goal was to build a website for an artisan, applying everything we had learned during our first semester. I used HTML and CSS to create the front end, and PHP to generate repetitive content, such as the products sold by the artisan and the product information tables. This project was a turning point for me: it taught me a lot about programming and confirmed my passion for back-end development and optimization.

SAE 205 : Cinema's Website

The cinema website is one of my biggest projects to date. I built it using HTML, CSS, JavaScript, PHP, and SQL. The goal was to create a website connected to a database, from which I could retrieve data to display information and into which users could add new data. The project also includes an authentication system built around sessions. Through this project, I learned how to structure and secure a website, and how to use forms properly.

Exo4 : Simon

Although it was not one of my biggest projects, I consider it one of the most important. I built it mainly with JavaScript, along with a little HTML and CSS. The goal was to recreate the game Simon using addEventListener, setTimeout, and setInterval. Through this exercise, I learned how to separate and organize my functions to keep my code simpler and easier to maintain.
